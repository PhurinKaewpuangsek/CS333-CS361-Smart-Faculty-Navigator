# Security Policy

## Supported Versions

Since this is a university/academic project, we currently only apply security updates and patches to the `main` branch. 

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly.

Instead, please send an email directly to **privatekoom@gmail.com**.

We will review the report and do our best to address the issue promptly. Thank you for helping keep this project secure!
