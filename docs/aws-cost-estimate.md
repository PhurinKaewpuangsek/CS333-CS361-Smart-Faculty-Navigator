## สรุป

ระบบออกแบบเป็น **serverless ทั้งหมด** ค่าใช้จ่ายเกือบทั้งหมดจึงอยู่ใน AWS Free Tier

| | สปรินต์นี้ (S3) | สปรินต์หน้า (+ DynamoDB + Lambda) | รวม/เดือน |
|---|---|---|---|
| ใช้งานปกติ (1,000 ครั้ง/เดือน) | $0.01 | $0.01 | **~$0.02 (฿0.60)** |
| ใช้งานหนักสุด (20,000 ครั้ง/เดือน) | $0.08 | $0.20 | **~$0.27 (฿9)** |

**ตลอดเทอม (4 เดือน) ไม่เกิน $1.10 (~฿36) หรือประมาณ 1% ของเครดิต AWS Academy**

## สปรินต์นี้ — เก็บเว็บไว้บน S3

Deploy หน้าเว็บ (ไฟล์ static ~1.6 MB) ขึ้น S3 ผ่าน GitHub Actions

| รายการ | ค่าใช้จ่าย |
|---|---|
| เก็บไฟล์ 5 MB | $0.0001 |
| อัปโหลดตอน deploy (~40 ครั้ง/เดือน) | $0.002 |
| คนเข้าเว็บโหลดไฟล์ | $0.004 – $0.07 |
| Data transfer | **ฟรี** (100 GB แรก/เดือน) |

**เหตุผลที่ถูก:** ไม่มีเซิร์ฟเวอร์เปิดค้างไว้ จ่ายเฉพาะตอนมีคนเข้าใช้จริง

---

## สปรินต์หน้า — เพิ่ม DynamoDB + Lambda

ย้ายข้อมูลห้อง 131 รายการจากไฟล์ JSON ไปเก็บใน DynamoDB แล้วให้ Lambda เป็นตัวดึงข้อมูล

| รายการ | ค่าใช้จ่าย |
|---|---|
| Lambda (ประมวลผล) | **ฟรี** — Free Tier ให้ 1 ล้านครั้ง/เดือน เราใช้ไม่ถึง 1% |
| DynamoDB (อ่านข้อมูล) | $0.01 – $0.20 |
| DynamoDB (เก็บข้อมูล ~1 MB) | **ฟรี** — Free Tier ให้ 25 GB |

**เหตุผลที่ถูก:** DynamoDB แบบ on-demand คิดเงินตามจำนวนครั้งที่อ่าน/เขียน ไม่ใช่ตามเวลาที่เปิดเครื่องทิ้งไว้

## การตัดสินใจที่ทำให้ต้นทุนต่ำ

ค่าใช้จ่ายจริงของระบบบนคลาวด์มาจาก **service ที่คิดเงินรายชั่วโมง** ไม่ใช่จำนวนผู้ใช้ ทีมจึงหลีกเลี่ยงทั้งหมด:

| ทางเลือกที่ไม่เลือก | ถ้าเลือกจะเสีย | เหตุผล |
|---|---|---|
| NAT Gateway (วาง Lambda ใน VPC) | ~$32/เดือน | เดินเครื่องตลอด แม้ไม่มีคนใช้ |
| RDS PostgreSQL แทน DynamoDB | ~$12–15/เดือน | ฐานข้อมูลเปิดค้าง 24 ชม. |
| AWS WAF | ~$5/เดือน | ไม่จำเป็น เพราะข้อมูลเป็น public read-only |

รวมสามข้อนี้คือ **~$50/เดือน** เทียบกับสถาปัตยกรรมที่เลือกจริงคือ **~$0.27/เดือน**

## ข้อจำกัดและข้อควรทราบ

- ใช้บัญชี **AWS Academy Learner Lab** (region `us-east-1`) — credential หมดอายุทุก ~4 ชม. จึงตั้ง deploy เป็นแบบสั่งเองไม่ใช่อัตโนมัติ
- ตัวเลขคำนวณจากขนาดไฟล์จริงใน repo และการประมาณจำนวนผู้ใช้ — ยังไม่มีข้อมูล production จริง
- ราคาอ้างอิง AWS `us-east-1` ณ วันที่จัดทำ ราคา AWS ปรับได้ (ตรวจสอบที่ https://calculator.aws/)
- ถ้าต้องการ HTTPS สามารถเพิ่ม CloudFront ได้โดย **ไม่มีค่าใช้จ่ายเพิ่ม** (Free Tier ให้ 1 TB/เดือน)
