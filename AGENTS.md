# 🤖 Project TORCH V2: AI Context & Rules

This is the system prompt and rulebook for all AI assistants working on Project TORCH.

## ⛔ Non-Negotiables
- **No direct pushes to `main`.** Always branch off `main`.
- **Branch naming:** Extract exactly from the `Set Branch Name as: > **<branch-name>**` block in the issue. No issue → no code.
- **No AI attribution.** Do not add bot co-authors, footers, or "Generated by AI" text anywhere.
- **No ClickOps.** All AWS infrastructure must be defined in `template.yaml`.
- **Never commit secrets.** Keep `.env` out of version control.
- **Leave `.github/workflows/` alone** unless the issue explicitly demands CI changes.

## 📌 Architecture
- **Frontend:** React 18, Vite, TypeScript, Tailwind CSS (S3 Hosted).
- **Backend:** AWS Lambda (Node.js 24.x) + Implicit API Gateway.
- **Database:** Amazon DynamoDB (On-Demand).
- **IaC:** AWS SAM (`template.yaml`).

## 📁 Boundaries & Dependencies
- `frontend/`: Install dependencies inside `frontend/`. No cross-imports to `functions/`.
- `functions/`: One folder per function (e.g., `functions/get-locations/`). Each function has its own `package.json`. Run `npm install` inside the function's folder.
- `template.yaml`: Single source of truth for cloud infrastructure.
- `scripts/`: Node.js built-ins only. No root dependencies.

## 🏗️ AWS SAM & DynamoDB (Strict Rules)
- **Implicit API Gateway Only:** Define API events under `Events:` on Lambda functions in `template.yaml`. **Do NOT** create an `AWS::Serverless::Api` resource.
- **CORS:** `template.yaml` `Globals` handles preflight, but you MUST return `"Access-Control-Allow-Origin": "*"` in Lambda response headers.
- **Testing:** Use `npm run bootstrap` to provision a Dev environment. Never run a naked `sam deploy` without `--config-env`.
- **Seeding:** Deploying IaC does not create data. DynamoDB tables start empty and must be seeded manually in Dev.

## 💻 Workflow
1. Sync `main`.
2. Branch using the issue's designated name.
3. Use **Matt Pocock AI Skills** to plan and build (e.g., `/grill-with-docs`, `/tdd`, `/implement`).
4. Keep commits atomic (Conventional Commits: `feat(scope): msg`).
5. Verify authorship (no AI tags).
6. Open PR to `main` with `Closes #N`.
7. **STOP.** Wait for human review. Do not merge.
